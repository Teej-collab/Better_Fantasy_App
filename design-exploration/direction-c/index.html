Direction C — Stadium Lights

The boldest swing: true OLED black, frosted-glass cards, cyan + violet floodlight accents, single-family Space Grotesk tracked uppercase. A disciplined, 2-color descendant of the app's own retired "Cosmic" theme — not a return to the old always-lit rainbow nav the team already found didn't work. Navigation trades the tab bar for a minimal floating dock plus a full side drawer.

Cards & motion

Floodlight glow is a static background wash behind hero moments only — never an animated ring on every card. That restraint is deliberate: the app's own history includes disabling an always-rotating glow ring app-wide after real crash/battery reports, and this direction is the one most tempted to repeat that mistake, so it's the one most explicit about not doing it.
