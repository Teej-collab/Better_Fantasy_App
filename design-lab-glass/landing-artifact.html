The Weekend — Design Lab, Round Two

Built Mobile First.
No Shrinking.

Four liquid-glass sports concepts, each designed at a fixed 390px phone canvas from the first line of CSS — there is no desktop layout to fall back on. Glass is real material: lensing, refraction, and specular light on the navigation and floating chrome, with the content underneath left fully legible, not a flat blur slapped on every card. The fourth reuses THE WEEKEND's own real brand colors instead of an invented palette.
